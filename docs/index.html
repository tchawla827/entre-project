03 / THE TAKEAWAY

We can locate heat.
We cannot predict spoilage yet.

Road cooling failure added the most exposure in the configured air-route single-disruption set. It ranked first in 197 of 200 changes to simulation assumptions—not 98.5% predictive accuracy.

Fish-quality measurements linked to real temperature histories are needed to calibrate spoilage.
