The full `pytest tests/digital_twin tests/models tests/data_pipeline -q` run passed **24 tests, 0 failures, 2 joblib/NumPy deprecation warnings** on 2026-10-28. Identical resolved input and seed reproduce the same run ID and interval table. Stage degree-hours sum to route degree-hours at 2 and 4 °C within numerical tolerance. Warming all stage setpoints under the same schedule cannot reduce exposure. Zero-length intervals have zero area; zero-duration stages add none. The difference is numerical integration error from endpoint interpolation, not model calibration error.
