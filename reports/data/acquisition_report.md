# Acquisition and inspection

Downloaded or extracted 329 immutable source files with SHA-256 checksums in `metadata/checksums.sha256`. The authoritative sensor repository is [DaFiF v1](https://data.mendeley.com/datasets/vx4ptwk3pb/1), DOI 10.17632/vx4ptwk3pb.1. Its API inventory lists 63 XLSX files and 2,536 JPEGs. All 63 spreadsheets were downloaded and verified against publisher SHA-256. Images are inventoried with file IDs and expected hashes in `metadata/dafif_official_inventory.json`; their ~10 MB each are unnecessary for gas-sensor data readiness. The local combined CSV and 33 workbook files are copied byte-for-byte under raw/local. The second combined CSV inside `Data_IIT2023150/Data/Dataset` has the same SHA-256 as the top-level copy. The README mentioned `Data_IIT2023150.zip`, but that ZIP was not present in the workspace; the extracted tree was audited instead.

The [rainbow trout v4 record](https://zenodo.org/records/23600663), DOI 10.5281/zenodo.23600663, packages 21.1 GB mainly of images. Its server supports HTTP byte ranges, allowing retrieval of **214 tabular/metadata ZIP members totaling ~1.2 MB** without the image payload. Every selected member passed ZIP CRC/size checks and has a SHA-256 in `metadata/trout_selected_manifest.json`; the full ZIP MD5 and central-directory inventory are recorded. Extracted files include 210 sensor CSVs, 21 individual laboratory TVC outcomes and a fillet-day availability matrix. Its CC BY 4.0 license permits reuse with attribution. The full 21 GB ZIP was not downloaded.

The [DaFiF article](https://pmc.ncbi.nlm.nih.gov/articles/PMC11528684/) XML supplies expert Table 3. Three current [MPEDA item, market and port workbooks](https://mpeda.gov.in/?page_id=438) cover FY1995-96 through 2025-26; each is an independent annual aggregate. [Berry citrus reefer data](https://data.mendeley.com/datasets/mvr7m6mcgp/2), DOI 10.17632/mvr7m6mcgp.2, supplied six CSVs. [Zenodo cold-room record](https://zenodo.org/records/15130001), DOI 10.5281/zenodo.15130001, supplied nine preprocessed sensor files in ZIP and an action log. [Smoked catfish package data](https://data.mendeley.com/datasets/tvsw53j89z/1), DOI 10.17632/tvsw53j89z.1, supplied a measured two-treatment outcome CSV and source analysis script. [NOAA shelf-life report](https://repository.library.noaa.gov/view/noaa/34680) and an [Indian cold-chain case study](https://dmeo.gov.in/sites/default/files/2021-08/Package1_Fisheries_CaseStudy1.pdf) were saved for bounded reference.

Investigated [Hammond Dryad](https://datadryad.org/dataset/doi:10.5061/dryad.6708r), DOI 10.5061/dryad.6708r; its `Supplemental_1.xlsx` endpoint returned HTTP 403, and general food-microbe data would not validate fresh fish. [Gilthead sea bream 0/4/8/12 °C study](https://pmc.ncbi.nlm.nih.gov/articles/PMC9367857/) and [horse mackerel 4/20 °C study](https://pmc.ncbi.nlm.nih.gov/articles/PMC9391519/) were inspected; machine-readable source-level paired replicate data were not located in their articles. The [spectroscopy companion](https://zenodo.org/records/3237542) was inspected separately; its article supplement contained classifier probabilities rather than temperature × quality observations. Search and candidate limitations are recorded in `metadata/dataset_registry.csv`. No public Indian export series pairing product temperature with terminal spoilage was located.
