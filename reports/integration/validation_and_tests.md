The latest machine-readable result is [verification.json](verification.json). The code now uses explicit `df["mode"]` indexing, the figures were regenerated, and validation passed. This was a presentation/validation defect, not a simulator result change. The Phase 4 API also added event-overlap rejection to the Phase 3 typed stage, so overlapping simultaneous thermal events no longer silently use event order.
