# Phase 4 final handoff — integrated thermal-exposure research system

**Status, 2026-10-28: Phase 4 engineering and scenario evaluation complete; calibrated fish spoilage prediction BLOCKED.** This file is the single entry point for results and downstream development. The service returns a versioned, evidence-scoped thermal simulation and limited original Phase 2 study diagnostics. It does not produce fresh-finfish spoilage probability, shelf life, or real Indian-shipment prediction reliability.

## What was implemented and executed

[`src/integration/api.py`](../../src/integration/api.py) exposes `execute(IntegrationRequest | dict, include_trace=True)` as the stable Phase 5 Python entry point. [`schemas.py`](../../src/integration/schemas.py) validates version 1 request fields, Celsius units, UTC time, route, mode, source scope, references, step and seed. The API reuses the Phase 3 simulator and Phase 2 inference, preserves provenance, separates simulated air from assumed product lag, and returns explicit null biological prediction with `NOT_CALIBRATED` capability status. Fresh-fish quality and spoilage-probability requests raise `UnsupportedCalibrationError`; there is **no silent exposure fallback**. Limited trout and smoked-catfish diagnostics retain their original within-study domains and are loaded only after SHA-256 verification against Phase 2's artifact manifest. DaFiF clusters remain descriptive only. See [architecture](architecture_and_contracts.md) and [capabilities](model_capabilities_and_blockers.md).

[`experiment_runner.py`](../../src/integration/experiment_runner.py) and [`cli.py`](../../src/integration/cli.py) ran **48 full route/mode/scenario simulations**: air and conditional sea, synthetic and two nonfish-proxy-shaped modes, eight scenarios each. Saved output contains **192** scenario/channel/reference rows, **1,344** stage rows, 48 complete trace Parquet files, event records, run/source/request manifest, 12 exact Shapley allocation rows, four net interaction rows, standardized equal-size events, low/central/high corner stress runs, and **2,400** paired Monte Carlo scenario rows. Both 2 and 4 °C are configurable comparison references, not universal safe/legal limits. Outputs are versioned and documented below. Phase 3's CLI/results remained operational; Stage now rejects overlapping thermal events explicitly.

Run from the repository root in the pinned Python 3.12.16 environment:

```powershell
.\.venv\Scripts\python.exe -m src.integration.cli run --all
.\.venv\Scripts\python.exe -m src.integration.cli analyze --all
.\.venv\Scripts\python.exe -m src.integration.cli validate --all
.\.venv\Scripts\python.exe -m pytest tests/integration tests/digital_twin tests/models tests/data_pipeline -q
```

The final full suite passed **32 tests, 0 failures**, with four known joblib/NumPy deprecation warnings during trusted, hash-verified local trout artifact loading. `validate --all` passed all conservation, Shapley, trace round-trip and biological-refusal checks, as recorded in [verification.json](verification.json). An initial validator/plot bug used pandas `.mode` as an attribute instead of the `mode` column; this was corrected, plots were regenerated and all checks rerun. Source code, configs, model artifacts, curated Parquet files, package/platform versions and SHA-256 hashes are recorded in the [provenance manifest](../../results/integration/provenance_manifest.json). The workspace has no Git repository; a commit SHA cannot be supplied. Fixed seeds: run suite **2404**; Phase 3 Monte Carlo routine **2403** (200 air, 100 sea draws). The manifest records each mode/scenario run ID and request. See [tests](validation_and_tests.md).

## Actual results and interpretation

For the **hypothetical 47 h air route**, baseline simulated air exposure above 2 °C is **15.0455 °C·h** (estimated-product-lag channel **11.8803 °C·h**). The 50 h combined road/airport/flight disruption yields air **128.0829 °C·h**, adding **113.0374 °C·h**; assumed product lag yields **124.3761 °C·h**. The modeled 2 h road refrigeration failure alone adds **55.8025 °C·h** air exposure; airport delay/door adds **37.3003**, flight excursion **19.9999**, storage setpoint +3 °C **24.5202**, destination delay **4.4946**, processing delay **2.9993**. Exposure per route hour is **0.3201 °C** baseline versus **2.5617 °C** combined, accounting explicitly for their 47/50 h durations. Identical Phase 3 config/version inputs reproduce its reference values exactly; no output was hardcoded in the experiment runner. [Scenario report](scenario_experiments.md), [comparison Parquet](../../results/integration/scenario_comparison.parquet).

For the **conditional hypothetical 375 h sea configuration**, baseline 2 °C air exposure is **13.4640 °C·h**; an 8 h vessel excursion adds **34.7802 °C·h**, and the 378 h combined road/seaport/vessel case reaches **140.3982 °C·h** (+**126.9342**). The long below-reference vessel interval explains the low baseline degree-hours despite longer duration. This does not prove biological viability, route plausibility, or superiority to air. MPEDA has separate aggregate chilled-product, EU-market and Cochin cargo marginals, not a chilled-finfish × Kochi × EU shipment record. Both routes and every stage duration/setpoint/event are assumptions, identified in the [Phase 3 handoff](../digital_twin/final_handoff.md).

Air baseline *physical stage* degree-hours above 2 °C are landing 0, processing **3.9402**, storage **0.2362**, road 0, airport **5.2424**, flight **0.7567**, destination **4.8701**; their sum is **15.0455**. Combined physical-stage values are 0, **3.9402**, **0.2362**, **54.4322**, **43.8426**, **20.7435**, **4.8882**, summing to **128.0829**. This is where modeled heat exposure occurs, including downstream carryover. Exact three-intervention Shapley allocates the *combined increase* differently: road **55.7699**, airport **37.2676**, flight **19.9999 °C·h**; sea road/seaport/vessel **55.7699/36.3841/34.7802**. Air net interaction relative to the sum of single effects is **−0.0653 °C·h** at 2 °C. See [attribution](stage_ranking_and_attribution.md) and [tables](../../results/integration/intervention_attribution.parquet).

Under equal 2 h, +3 °C stage perturbations, airport and flight each add **6.0000 °C·h** above 2 °C in the air route, whereas cold storage adds **2.9018**. At 4 °C, the dominant standardized stage changes to destination. The nominal road-first ranking therefore depends on disruption magnitude and reference; Phase 3's brief-road and strong-flight tests also reverse it. In bounded paired assumption draws, road is the largest **single intervention** in **197/200** air draws at 2 °C and **193/200** at 4 °C, and 100/100 sea draws for both references. The **physical stage** with most combined-case air exposure is road in **137/200** air draws (airport in 63) and **75/100** sea draws (seaport in 25). Air combined extra-exposure median is **115.9022 °C·h** (5th/95th draw quantiles **83.8888/139.6812**); sea median **130.2725** (**91.8932/159.9828**). These are *hypothetical input-range summaries*, not biological prediction intervals. Low/central/high corner stresses produce air combined deltas **69.0180/113.0374/161.4560 °C·h** and sea **77.9610/126.9342/185.8205**. See [robustness](robustness_and_uncertainty.md).

Nonfish proxy replay changes the air baseline to **15.4315** (citrus) or **15.8737 °C·h** (generic cold room); sea baseline becomes **13.0315** or **14.2680 °C·h**. These are detrended residual shapes applied to modeled setpoints, never logged Indian seafood route temperatures or fish core. Phase 3's 15-minute to 5-minute air-baseline integration difference is **0.0635%**; it measures numerical discretization, not physical calibration. [Proxy manifests](../digital_twin/proxy_replay_manifests.json), [validation](validation_and_tests.md).

## Results, figures and Phase 5 contract

The stable output schema is **v1**. [`scenario_comparison.parquet`](../../results/integration/scenario_comparison.parquet) has one row per route, mode, scenario, channel and reference, including duration, peak/mean °C, hours above reference, maximum continuous excursion hours, °C·h total, per-route-hour exposure, absolute/relative baseline delta, baseline/run IDs, source class and prediction status. Relative delta is **null** where baseline degree-hours are zero. [`stage_contributions.parquet`](../../results/integration/stage_contributions.parquet) adds UTC stage boundaries, exposure and nullable fraction of route total; [`physical_stage_rankings.parquet`](../../results/integration/physical_stage_rankings.parquet) records the top stage or undefined status for each route/mode/scenario/channel/reference. [`events.parquet`](../../results/integration/events.parquet) records disruption timing and recovery/censoring. [`intervention_attribution.parquet`](../../results/integration/intervention_attribution.parquet), [`interactions.parquet`](../../results/integration/interactions.parquet), [`standardized_interventions.parquet`](../../results/integration/standardized_interventions.parquet), [`stress_profiles.parquet`](../../results/integration/stress_profiles.parquet), [`sensitivity_draws.parquet`](../../results/integration/sensitivity_draws.parquet), [`ranking_draws.parquet`](../../results/integration/ranking_draws.parquet), [`stage_rank_draws.parquet`](../../results/integration/stage_rank_draws.parquet) and [`monte_carlo_convergence.parquet`](../../results/integration/monte_carlo_convergence.parquet) provide analysis layers. The [run manifest](../../results/integration/run_manifest.json) maps 48 individual traces, requests and provenance; the [capability matrix](../../results/integration/capability_matrix.json) and [claim–evidence matrix](../../results/integration/claim_evidence_matrix.json) communicate supported and blocked outputs. Ten legible PNG figures are in [`figures/integration/`](../../figures/integration/); [chart captions](claim_evidence_matrix.md) state precisely what each supports.

Phase 5 can call:

```python
from src.integration import execute
result = execute({"schema_version": 1, "target": "thermal_exposure",
                  "route": "air", "scenario": "road_failure",
                  "mode": "synthetic", "references_c": [2.0, 4.0]}, include_trace=False)
print(result["status"], result["run_id"])
print(result["thermal_exposure"]["route"]["air"]["references"]["2.0"]["degree_hours"])
```

The example returns `SIMULATED_EXPOSURE_ONLY` and about **70.8480 °C·h** for that exact configured road scenario. A [complete generated v1 response example](../../results/integration/example_response.json) includes the full nested route, stage and event metrics, request, source provenance, explicit `prediction: null`, unavailable reason, capabilities, and `trace: null` because the example sets `include_trace=False`. `include_trace=True` returns interval rows in memory. The dashboard should display route/mode/scenario/reference and channel filters; time traces and stage boundaries; total/per-hour exposure; stage decomposition and intervention attribution as distinct charts; sensitivity/rank stability; source/provenance; and prominent `NOT_CALIBRATED` states. It must keep air and estimated-product channels distinct, show null baseline-relative percentages as undefined, refuse unsupported biological requests visibly, and never style °C·h as a spoilage percentage. No polished dashboard is included in Phase 4.

## Scientific readiness

The targeted [public data re-audit](public_data_reaudit.md) found no new verified specimen-linked multi-temperature fresh-fish quality dataset or independent Indian shipment outcomes that unlock the original biological objective. Phase 1 data include 27,120 DaFiF sensor readings without linked expert labels, 21 individual nominal-4 °C trout TVC assays separate from monitored sensor fillets, aggregate MPEDA exports, and nonfish temperature proxies. No Gradient Boosting freshness classifier, variable-temperature fresh-finfish kinetics, spoilage probability or field-validity estimate was fitted or enabled. The [claim–evidence matrix](claim_evidence_matrix.md) distinguishes engineering verification, simulated scenario findings, limited within-study biological checks and blocked validation claims.

To unlock actual spoilage-risk prediction, collect linked shipment/lot/specimen/logger/assay IDs; repeated fish-core and air temperatures across multiple controlled temperatures and real journeys; species/product/ice/packaging state; initial and arrival microbial/sensory endpoints with methods, units, detection limits and biological replicates; and independent exporters/routes or later shipments for a prespecified holdout. The proposed [field linkage schema](../../configs/integration/field_linkage_schema.yaml) and Phase 1 [blocked-data request](../data/blocked_data_requests.md) specify the minimum design. Repeated logger measurements are not independent fish or shipment samples. This data gap is a **scientific blocker**, not an implementation failure.
