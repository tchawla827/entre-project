# Targeted public-data re-audit (2026-10-28)

Search scope: public Zenodo, Dryad and Mendeley records for specimen/batch-linked fresh-fish temperature histories, measured quality endpoints across temperatures, and independent Indian export shipments. This was a targeted eligibility check, not a systematic review. No new dataset was downloaded because the inspected candidates did not meet the minimum linkage and temperature-range gates for the stated prediction task.

| Candidate | What the primary record establishes | Eligibility decision |
|---|---|---|
| [Rainbow-trout multimodal v4](https://zenodo.org/records/23600663) | 21 destructive TVC assays from fillets separate from the 59 imaging fillets; all stored at nominal 4 °C. | Already curated in Phase 1/2. Does not supply specimen-paired sensor labels or multi-temperature kinetics. |
| [HFQA salmon imaging subset](https://zenodo.org/records/20508624) | One salmon pack imaged on 16 storage days; record describes visual progression and explicitly contains templated acquisition placeholders. | No measured microbiological/sensory endpoint linked to a multi-temperature fish trace, no independent packs in public subset. Not eligible; license/metadata would need verification before reuse. |
| [TraceMyFish quality-monitoring deliverable](https://zenodo.org/records/7453423) | Public project documentation discusses fish quality monitoring and 2/4 °C conditions. | Documentation is not a verified downloadable, specimen-linked temperature–quality table suitable for calibration. |

The source check does not prove that no such dataset exists anywhere; it establishes that none of these inspected records unlocks the current fresh-finfish variable-temperature or Indian-shipment validation gates. Phase 1's [blocked-data requests](../data/blocked_data_requests.md) remain applicable. No researcher or exporter was contacted.
