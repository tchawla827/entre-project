# One-command setup verification

`run_project.py` is the cross-platform entry point. From a project copy with Python 3.12 and internet access, Windows can use `py -3.12 run_project.py` (or `python run_project.py` when that command points to Python 3.12); POSIX can use `python3.12 run_project.py`. The script creates `.venv` if needed, installs pinned dependencies, fetches public sources, curates and validates observed data, trains the defensible bounded study models, regenerates Phase 3 air/sea simulations and analyses, regenerates Phase 4 integrated results, validates both, runs tests, then launches Streamlit. It executes every stage from the repository root and stops with a nonzero exit code when a required stage fails. [`last_run.json`](last_run.json) records stage commands, exit codes and elapsed seconds.

The complete **online-path** one-command rebuild was executed here with `run_project.py --skip-install --no-dashboard`: all **13 stages passed** in about **127 seconds** using the existing pinned environment and cached raw source bytes. It fetched/rechecked public sources, curated and validated data, rebuilt Phase 2 models, regenerated both Phase 3 routes and all 48 Phase 4 integrated runs, produced 2,400 analysis draw rows, passed the integrated validator, and finished with **41 tests passed**. The complete **offline** path also passed with `--offline --skip-install --no-dashboard`. The pinned `pip install -r requirements.txt` succeeded separately. Fetch reported one HTTP 403 for the optional Hammond/Dryad supplement; that general research file is not used by the curated thermal model. This verifies orchestration with cached source bytes. An entirely empty machine and uncached downloads have not been tested end to end here.

The repository's `.gitignore` excludes `data/raw/` and `data/curated/`. A new checkout therefore relies on the online fetch; a copied folder containing raw data can run with `--offline`. The original local files `combined_dataset.csv` and `Data_IIT2023150/Data/Dataset/` must be supplied with the project; the runner checks for them before work begins. Reproducing online acquisitions depends on the public hosts continuing to serve their files, including Zenodo's range access for the selected trout CSVs. The command does not create a fresh-finfish spoilage predictor; its biological calibration remains blocked by missing linked observations.
